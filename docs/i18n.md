# Internationalization (i18n)

Recall ships two locales out of the box — **English (`en`)** and **Bahasa
Indonesia (`id`)** — because the app explicitly targets Indonesian learners
(UTBK/SNBT, CPNS, med/pharmacy boards). Contributions must keep both in sync.

## How it works

- Library: `i18next` + `react-i18next` + `i18next-browser-languagedetector`
  (see `src/lib/i18n.ts`).
- Locale resources are static JSON imports: `src/locales/en.json`,
  `src/locales/id.json`.
- `fallbackLng: "en"` — any missing key resolves to the English string, never a
  raw key code in the UI.
- Language is auto-detected from `localStorage` then `navigator`, and the
  detected language is written to `<html lang>`.
- In components, strings are read with `t("namespace.key")` from
  `react-i18next`.

## Adding or editing a string

1. Add the key under the same **namespace** in **both** `en.json` and `id.json`.
   Namespaces mirror features: `app`, `nav`, `library`, `dashboard`, `deck`,
   `study`, `settings`, `sync`, etc.
2. Keep keys nested (dot-separated namespaces), not flat.
3. Run the app and visually confirm both languages render — there is no
   automated key-parity test yet, so drift is caught by review/eyeballing.

```jsonc
// en.json
"deck": {
  "newCard": "New card",
  "cardsDue": "{{count}} due"        // interpolation
}

// id.json
"deck": {
  "newCard": "Kartu baru",
  "cardsDue": "{{count}} jatuh tempo"
}
```

```tsx
import { useTranslation } from "react-i18next";
const { t } = useTranslation();
return <button>{t("deck.newCard")}</button>;
```

## Interpolation

Use `{{var}}` placeholders. They are filled at render time and are
**not** translated:

```json
"level": { "label": "Level {{level}}" }
```

## Plurals — use `_one` / `_other`

i18next v21+ plural syntax. **Never use legacy `_plural`.** Provide a `_one`
and a `_other` form:

```jsonc
"library": {
  "decks_one": "{{count}} deck",
  "decks_other": "{{count}} decks"
}
```

```tsx
t("library.decks", { count: 1 });  // "1 deck"
t("library.decks", { count: 3 });  // "3 decks"
```

## Adding a new language

1. Create `src/locales/<code>.json` (copy `en.json` as the base, translate).
2. Register it in `src/lib/i18n.ts`:
   ```ts
   import xx from "@/locales/xx.json";
   resources: { en: { translation: en }, id: { translation: id }, xx: { translation: xx } }
   ```
3. Confirm the language appears in the settings language picker (if it's
   data-driven) or add it there.

## Rules of thumb

- Every user-facing string goes through `t()`. Hard-coded UI text is a bug.
- Never put HTML/markup in translation values; rely on React components.
- Keep both locale files at key parity. Missing keys fall back to English
  silently — so a missing `id` key won't crash, but it will show English to
  Indonesian users.
- Don't translate internal/logging strings.
